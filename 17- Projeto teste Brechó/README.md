# 17- Projeto teste Brechó

Site de catálogo de roupas para brechó com informações de contato.

## Funcionalidades

### 🛍️ Catálogo de Produtos
- Exibição em grid responsivo
- Cards com imagem, nome, categoria, tamanho e preço
- Botão "Tenho interesse" que direciona para o WhatsApp

### 🔍 Busca e Filtros
- Busca por nome, marca ou cor
- Filtro por categoria (Feminino, Masculino, Infantil, Acessórios, Calçados)
- Filtro por tamanho

### 📍 Informações de Contato
- Endereço do brechó
- Horário de funcionamento
- Botão de WhatsApp para contato
- Mapa de localização

### 📱 Design Responsivo
- Layout adaptável para desktop e mobile
- Menu hamburger para dispositivos móveis
- Botão flutuante do WhatsApp

## Como Usar

1. Abra o arquivo `index.html` no navegador
2. Navegue pelo catálogo de produtos
3. Use os filtros para encontrar peças específicas
4. Clique em "Tenho interesse" para falar no WhatsApp
5. Veja as informações de contato e localização

## Tecnologias Utilizadas

- HTML5
- CSS3 (com variáveis CSS e Grid/Flexbox)
- JavaScript vanilla
