🛠️ Principais Conceitos Desenvolvidos
Backend & APIs REST
Configuração de servidores utilizando Express.

Manipulação de requisições e respostas utilizando o formato JSON.

Utilização correta dos verbos HTTP (GET, POST, PUT, PATCH, DELETE) alinhados aos status de resposta apropriados (200 OK, 201 Created, 400 Bad Request, 404 Not Found).

Estruturação de arquitetura limpa (Separando Rotas, Controllers e Models).

Banco de Dados (MongoDB)
Modelagem de dados flexível e escalável com Mongoose.

Operações completas de CRUD persistindo informações diretamente na nuvem (MongoDB Atlas) ou localmente.

Consultas e filtros em documentos e coleções.
